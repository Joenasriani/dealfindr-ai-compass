# DealFindr Compass — Global Price Comparison

DealFindr Compass is a browser-based price-comparison and deal-discovery prototype.

## Purpose

The application is designed to compare products and offers across sellers, organize price information, and help users inspect potential purchasing options in one place.

## Status

Comparison-tool prototype. Prices, availability, seller terms, taxes, delivery charges, and regional restrictions should be verified with the seller before purchase.

## Run locally

```bash
npm install
npm run dev
```
